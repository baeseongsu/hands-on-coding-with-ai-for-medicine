# 02. 도메인 뷰

[`README.md`](./README.md)의 범위, 멈추고 물어야 할 때, 참고 자료가 함께 적용됩니다.

## 끝났을 때 무엇이 참이 되는가

환자 화면에서 그 환자의 진단, 처방, 검사 결과를 도메인별로 나누어 볼 수 있다. 진단과 검사는 코드나 항목 번호가 아니라 사람이 읽을 수 있는 이름으로 표시된다.

## 무엇으로 증명하는가

```bash
npm run build
npm test -- --run
```

## 성공 기준

아래가 모두 참이 되면 달성한 것으로 보고 멈춘다.

1. `npm run build`가 성공한다.
2. `npm test -- --run`이 성공하고, 테이블 join에 대한 테스트가 하나 이상 있다.
3. `10000032`의 화면에서 진단, 처방, 검사 결과를 각각 구분해서 볼 수 있다.
4. 진단이 `d_icd_diagnoses`의 설명과 함께 표시되고, 검사가 `d_labitems`의 항목명과 함께 표시된다.
5. 해당 도메인에 기록이 없는 환자에게는 빈 상태가 의도적으로 표시되고, 화면이 깨지지 않는다.
6. 각 기록이 어느 입원(`hadm_id`)에 속하는지 화면에서 알 수 있다.
7. 1단계에서 만든 화면이 그대로 동작한다.

기준을 스스로 완화하지 않는다. 달성하지 못하면 달성하지 못했다고 보고한다.

## 이 단계에서 하지 않는 것

- 여러 도메인을 하나의 시간순 흐름으로 합치는 것은 3단계다.
