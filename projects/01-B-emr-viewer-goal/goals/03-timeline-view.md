# 03. 시간축 뷰

[`README.md`](./README.md)의 범위, 멈추고 물어야 할 때, 참고 자료가 함께 적용됩니다.

## 끝났을 때 무엇이 참이 되는가

환자 화면에서 입원, 퇴원, ICU 입실과 퇴실, 진단, 처방, 검사 결과를 하나의 시간순 흐름으로 읽을 수 있다.

## 무엇으로 증명하는가

```bash
npm run build
npm test -- --run
```

## 성공 기준

아래가 모두 참이 되면 달성한 것으로 보고 멈춘다.

1. `npm run build`가 성공한다.
2. `npm test -- --run`이 성공하고, 정렬이 원본 배열 순서가 아니라 시각 기준임을 증명하는 테스트가 있다.
3. `10000032`의 화면에서 여러 도메인의 사건이 하나의 흐름에 함께 나타난다.
4. 각 사건에 시각, 도메인, 짧은 제목, 어느 입원에 속하는지가 표시된다.
5. 사건 종류를 색 없이도 구분할 수 있다.
6. 1단계와 2단계에서 만든 화면이 그대로 동작한다.

기준을 스스로 완화하지 않는다. 달성하지 못하면 달성하지 못했다고 보고한다.
