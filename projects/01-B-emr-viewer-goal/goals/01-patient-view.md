# 01. 환자 기본 뷰

[`README.md`](./README.md)의 범위, 멈추고 물어야 할 때, 참고 자료가 함께 적용됩니다.

## 끝났을 때 무엇이 참이 되는가

`data/mimic-iv-clinical-database-demo-2.2.zip` 하나를 읽어 정적 데이터를 생성하고, Patient ID로 환자를 찾아 그 환자가 누구이고 언제 입원했는지 볼 수 있는 화면이 이 디렉터리에서 실행된다.

## 무엇으로 증명하는가

```bash
npm run build
npm test -- --run
shasum -a 256 data/mimic-iv-clinical-database-demo-2.2.zip
```

파생 데이터 재생성은 스스로 만든 명령으로 확인한다. 어떤 명령인지 `README.md`에 적는다.

## 성공 기준

아래가 모두 참이 되면 달성한 것으로 보고 멈춘다.

1. `npm run build`가 성공한다.
2. `npm test -- --run`이 성공하고, 데이터 변환에 대한 테스트가 하나 이상 있다.
3. Patient ID `10000032`를 검색하면 그 환자가 결과에 나오고, 없는 ID를 검색하면 애플리케이션이 멈추지 않는다.
4. 그 환자의 화면에 `patients`와 `admissions`에서 온 기본 정보와 입원 기록이 표시된다.
5. 브라우저에서 URL을 직접 입력하거나 새로고침해도 그 화면이 동작한다.
6. 생성된 파생 데이터를 모두 지운 뒤 문서화된 하나의 명령으로 다시 만들 수 있다.
7. ZIP의 SHA-256이 참고 자료의 값과 같다.
8. `README.md`에 설치, 데이터 준비, 실행, 테스트, 빌드 명령이 적혀 있고, 그 명령만 따라 해서 처음부터 실행할 수 있다.

기준을 스스로 완화하지 않는다. 달성하지 못하면 달성하지 못했다고 보고한다.

## 이 단계에서 하지 않는 것

- 진단, 처방, 검사 결과는 2단계다.
- 시간축 통합은 3단계다.
