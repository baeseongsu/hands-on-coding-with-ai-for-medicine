## 무엇을 읽고 무엇을 안 읽는가

- 여러분이 읽을 것: 이 디렉터리의 파일, `specs/roadmap.md`에서 지금 단계의 목표 한 줄
- 에이전트가 읽을 것: `specs/constitution.md`, `specs/mission.md`, `specs/tech-stack.md`
  - 원문을 붙잡고 읽지 말 것. 01에서 에이전트가 요약해 줌
- 여러분이 쓸 것: 단계마다 만드는 `specs/<번호>-<단계이름>/`의 `spec.md`, `plan.md`, `tasks.md`, `checklist.md`
